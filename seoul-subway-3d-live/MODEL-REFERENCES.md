# K-pop place model references

These original 3D sketches use exterior photos and operator descriptions as visual
references. They are approximate landmarks, not surveyed building models. The
source photographs, signage, logos, map tiles, and 3D meshes are not embedded.
Marker coordinates remain approximate OpenStreetMap points; see
[`LICENSE-DATA.md`](LICENSE-DATA.md).

## NAVER Map benchmark

NAVER describes its [Street View 3D](https://www.navercorp.com/media/pressReleasesDetail?seq=32200)
as linking selectable buildings to place details, with a visual highlight on
selection. Its [Flying View 3D](https://www.navercorp.com/en/media/pressReleasesDetail?seq=33482)
uses aerial and street-level imagery to reconstruct realistic landmark views.
This project cannot match that photographic reconstruction with the available
geometry. It adopts the relevant interaction principles: approximately site-sized
massing at close zoom, simple points at city scale, a restrained selected-place
highlight, and a linked place card. These are independent drawings and code.
