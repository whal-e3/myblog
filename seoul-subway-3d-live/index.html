BEHIND THE MAP

A network, not a tunnel survey.

Seoul Subsurface turns a geographic rail network into an explorable three-dimensional map.

What you are looking at

All lines, stations and links in the bundled August 24, 2026 network snapshot are included. Positions use a local geographic projection; the map includes connected regional and light-rail lines, not only Lines 1–9. This community-mapped snapshot is not a guarantee of current operational coverage.

Height is a visualization device. Routes have slight vertical offsets so overlaps are easier to read. These offsets do not describe actual tunnel depths, elevation, station interiors, underground floors or construction geometry. Four-car 3D trains are generic models, not exact fleet replicas. When connected, their stations and timestamps come from TOPIS, not continuous GPS positions. Train scale, orientation and short estimated movement are illustrative.

The source’s mapped path is retained for 842 segments. One Suin–Bundang segment has no source path and uses a straight station-to-station connector, identified in the downloadable data. Segment endpoints are aligned to the source station centers. Route colors use the source network palette. The light/dark blue interface is Seoul Metro–inspired and is not an official transit product. English names without a curated alias are automatic transliterations, not official signage.

Live positions, with honest limits

When configured and available, the server fetches reports for its enabled routes from Seoul TOPIS realtimePosition. The browser does not receive the API key. The inspector shows the provider's train number, station, status, direction, destination and report time. The map has 24 routes; provider feed support, server configuration and current availability are separate. Incheon Lines 1 and 2, Gimpo Goldline, Everline and Uijeongbu currently have no live adapter and remain map-only. No synthetic fleet is substituted for a missing or failed feed.

Freshness is based on each provider timestamp. Reports older than 90 seconds or affected by connection errors are marked stale; reports older than five minutes disappear. A newly observed adjacent station is reached by a three-second visual transition. After a fresh departure, a known previous station and one unambiguous onward track can produce at most a small estimated movement over three seconds, then the model holds. This is illustrative, not a prediction of actual tunnel position or arrival time. Missing or ambiguous station names and unknown timestamps are excluded. The map stays available when the live feed is not connected.

LIVE DATA / 실시간 열차

Live train reports.

The server supplies live observations for configured routes when their feeds are available. The browser does not need an API key.

The feed uses Seoul's station-level train reports. Service interruptions or stale provider reports can leave the map without live trains. The map itself remains available.

What the 3D trains represent

Actual train identifiers and reported stations/statuses, not continuous GPS. No timetable-based or random trains. Missing or failed feeds stay empty or stale. Movement between two adjacent observed stations is visual interpolation. After a fresh departure, a train with one unambiguous onward track may move a short estimated distance for three seconds, then hold. The estimated position is illustrative and may differ from the train's real location.

Feed coverage

The server advertises which routes it supports and enables. The table reports each route separately; enabled routes are requested only while visible. A supported route may still be unavailable, empty, or over the server's request cap. Five mapped routes have no live adapter and remain map-only.
