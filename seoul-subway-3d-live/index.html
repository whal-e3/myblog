BEHIND THE MAP

A network, not a tunnel survey.

Seoul Subsurface turns a geographic rail network into an explorable three-dimensional map.

What you are looking at

All lines, stations and links in the bundled August 24, 2026 network snapshot are included. Positions use a local geographic projection; the map includes connected regional and light-rail lines, not only Lines 1–9. This community-mapped snapshot is not a guarantee of current operational coverage.

Height is a visualization device. In the exploded view, the surface map sits above the separated rail layers so overlaps are easier to read. These layers do not describe actual tunnel depths, elevation, station interiors, underground floors or construction geometry. Four-car 3D trains are generic models, not exact fleet replicas. When connected, their anchors are reported stations from TOPIS, not continuous GPS positions. Train scale, orientation and brief report-to-report smoothing are illustrative.

The source’s mapped path is retained for 842 segments. One Suin–Bundang segment has no source path and uses a straight station-to-station connector, identified in the downloadable data. Segment endpoints are aligned to the source station centers. Route colors use the source network palette. The light/dark blue interface is Seoul Metro–inspired and is not an official transit product. English names without a curated alias are automatic transliterations, not official signage.

Live positions, with honest limits

When available, the server fetches Line 2 reports from Seoul TOPIS realtimePosition. The browser does not receive the API key. The inspector shows the provider's train number, station, status, direction, destination and report time. The other mapped lines remain map-only. No synthetic fleet is substituted for a missing or failed feed.

Freshness is based on each provider timestamp. Reports older than 90 seconds or affected by connection errors are marked stale; reports older than five minutes disappear. Smoothing only joins two received adjacent-station reports over 1.2 seconds. No prediction beyond the latest reported station is made. Missing or ambiguous station names and unknown timestamps are excluded. The map stays available when the live feed is not connected.

LIVE DATA / 실시간 열차

Line 2 live reports.

The server supplies live observations when its feed is available. The browser does not need an API key.

The feed uses Seoul's station-level train reports. Service interruptions or stale provider reports can leave the map without live trains. The map itself remains available.

What the 3D trains represent

Actual train identifiers and reported stations/statuses, not continuous GPS. No timetable-based or random trains. Missing or failed feeds stay empty or stale. Smooth motion is a brief transition between two reports already received, not an estimate of the train's current in-tunnel position.

Feed coverage

Only Line 2 is enabled for live reports in this map. Other lines remain explorable as map data. Line visibility controls which reports are displayed.
